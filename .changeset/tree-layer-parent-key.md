Bind `tree.parent` to `U` in `treePreset` and `Shift+U` in `shiftedTreePreset`, so page-wide Tree and List layers can return to a parent row. Top-level rows stay highlighted. Keep secondary hints hidden by default in named layers too; pass `all` to include the parent key in legends.
